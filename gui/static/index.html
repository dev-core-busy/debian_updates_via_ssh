Ziel und Anmeldung

Wartungszugang einrichten

Legt auf dem Ziel einen eigenen Benutzer mit SSH-Schlüssel an. Per sudo darf er nur das Hilfsskript für die Paketverwaltung ausführen (Updates, Installationen, Distributions-Upgrade). Fehlt sudo, wird es über den Tunnel installiert.

Paket installieren

PaketVersionArchGrößeBeschreibung
  1. Simulation – lädt die Paketlisten des neuen Release in ein Testverzeichnis und zeigt, was passieren würde. Am System ändert sich dabei nichts.
  2. Upgrade – Quellen umstellen (mit Sicherung), alles herunterladen, dann installieren. Die Installation läuft auf dem Ziel unabhängig von der SSH-Verbindung weiter.
  3. Neustart – danach mit dem neuen Kernel neu starten.

Zusätzlich erlaubte Repository-Hosts

Debian-Server (*.debian.org) sind immer erlaubt. Drittanbieter-Quellen des Ziels (z. B. download.docker.com) müssen hier freigegeben werden.
